# 静态资源外置指南

> 目标：避免大体积媒体资源重新进入 Git，让仓库保持轻量。

## 触发条件

- 新增或迁移视频、图片、音频、PDF 等二进制静态资源。
- 单个文件接近或超过 `1MB`。
- 文件属于示例、文档、模板预览、测试素材或可从外部存储恢复的资源。

## 推荐流程

1. 将资源按仓库相对路径放入 `Document/` 上传包。
2. 上传到公司 Nextcloud，保持目录结构一致。
3. 在根 `README.md` 的 “Nextcloud 静态资源” 章节记录网盘目录、查找规则和文件清单。
4. 对已上传资源使用 `git rm --cached` 移除 Git 跟踪，保留本地副本。
5. 在 `.gitignore` 中加入 `Document/` 和资源精确路径。

## 校验点

- `git ls-files` 中没有目标大文件。
- 本地工作区仍保留目标文件。
- `git check-ignore --stdin` 能匹配所有目标路径。
- README 清单与实际外置资源路径一致。

## 历史清理

当前快照移除后，`.git` 历史中仍可能保留旧对象。释放历史空间需要单独维护窗口，执行 `git filter-repo` 或等价流程，并安排强推、远端 GC、协作者重新同步。
