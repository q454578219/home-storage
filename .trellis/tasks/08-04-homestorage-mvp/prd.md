# 家庭物品存储管理 App MVP（可视化储物地图）

## Goal

解决"家里东西放哪了"的问题：用户拍下柜子/储物空间的照片，在照片上点击标记点位（格子），每个点位挂多张物品照片，用语音或手动输入物品名称，之后用文字搜索即可定位物品在哪个柜子的哪个位置。

## 已确认需求

### 柜子管理
- 首页：卡片网格展示所有柜子（照片缩略图 + 名称 + 分类标签）
- 新建柜子：拍照或从相册选照片 → 命名（语音输入或手动文字输入）→ 选择分类
- 分类：预设（客厅/卧室/书房/厨房/卫生间/阳台/其他）+ 自定义分类；首页按分类筛选
- 管理操作：重命名、改分类、换封面照片、删除（连带删除其点位和物品）

### 可视化点位
- 柜子照片上点击添加点位，点位代表一个格子/位置
- 支持长按移动点位、点击删除点位
- 点击点位查看详情

### 点位物品
- 一个点位可挂多张物品照片（拍照或从相册选择）
- 每张照片用**语音输入或手动输入**物品名称/描述，存入搜索索引
- 支持删除照片、随时编辑物品文字

### 语音输入
- 系统 SpeechRecognizer（无需 API Key、免费）
- 用于：柜子命名、物品名称/描述录入
- 语音识别失败时可随时切换手动输入

### 文字搜索
- 搜索范围：物品名称文字 + 柜子名称 + 分类名
- 结果形态：匹配列表（物品命中卡片：缩略图+名称+位置；柜子命中卡片）→ 点击物品命中 → 跳转柜子照片并高亮对应点位

### 数据存储
- 纯本地：Room 数据库（柜子/分类/点位/物品索引）+ App 内部文件目录（图片）
- 完全离线可用（除语音识别依赖系统服务）

### 文字搜索
- 搜索范围：物品 AI 识别文字 + 柜子名称 + 分类名
- 结果形态：匹配列表（物品命中卡片：缩略图+名称+位置；柜子命中卡片）→ 点击物品命中 → 跳转柜子照片并高亮对应点位

### 数据存储
- 纯本地：Room 数据库（柜子/分类/点位/物品索引）+ App 内部文件目录（图片）
- 支持管理操作全链路（见上）

## 技术选型（已确认）

- **数据存储**：Room + 本地文件
- **平台**：Android，Kotlin + Jetpack Compose（minSdk 29，targetSdk 36）
- **UI 方案**：Material 3（官方扁平化设计体系）+ 定制主题——品牌主色板、浅灰背景、大圆角卡片、低阴影、顶部搜索栏；不引入第三方 UI 库
- **图片选择**：系统相册（Photo Picker）+ CameraX 拍照
- **语音输入**：系统 SpeechRecognizer（无外部依赖、无 API Key）
- **AI 识别**：不引入（MVP 砍掉，后续迭代再说）

## Acceptance Criteria

- [ ] 新建柜子：拍照/相册选图 → 语音/手输命名 → 分类选择 → 首页出现柜子卡片
- [ ] 柜子照片上点击可添加点位，点位可长按移动、删除
- [ ] 点位详情可添加多张物品照片（拍照/相册）
- [ ] 物品照片可用语音或手动输入名称文字，可编辑/删除
- [ ] 搜索物品文字/柜子名/分类名能命中，点击结果跳转柜子照片并高亮点位
- [ ] 首页按分类筛选生效
- [ ] 柜子重命名/改分类/换封面/删除生效，删除连带点位和物品
- [ ] 完全离线可用（不含语音识别依赖的系统服务）

## Out of Scope（后续迭代）

- 数据导出/备份

- 柜子照片自动识别点位
