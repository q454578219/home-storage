# 户型图模式：空间定位柜子

## Goal

解决"柜子在哪个空间位置"的直观性问题：照片只能表达柜子正面，无法表达它在家里的位置（如两面墙都有柜子时分不清）。上传户型图后，点击户型图上的位置即可挂载柜子，形成"户型图 → 柜子"的空间地图。

## 已确认需求（用户已拍板）

### 户型图管理
- 支持**多张户型图**（每张 = 一层/一个区域），列表页管理（新增/删除/重命名）
- 户型图来源：拍照或相册选图（复用现有 ImagePicker）
- 删除户型图：只置空柜子的 `floorPlanId`，**不删除柜子**（防误删）

### 户型图详情（核心交互）
- 点击户型图空白处 → 弹出操作面板：**新建柜子**（复用新建柜子流程，创建后自动挂到点击位置）/ **挂载已有柜子**（选择列表）
- 已挂柜子在户型图上显示标记（名称 + 封面缩略图），点击跳转柜子详情
- 支持长按移动柜子标记（复用点位拖动的手势思路）
- 标记坐标用**归一化比例 0~1**（与点位坐标同思路，换图不漂移）

### 首页入口
- 首页顶部加"户型图"图标按钮 → 户型图列表页
- 不打扰原有主流程（柜子网格仍是主入口）

### 兼容性
- `CabinetEntity.floorPlanId` 可空 → 老用户、未挂载柜子完全不受影响
- 功能可选，不强制使用

## 第一版明确砍掉

- 户型图上的房间标注（后续版本加）
- 户型图内嵌套"墙"层级（一张图直接挂柜子，够用）
- 自动识别户型图结构（AI 后续再说）

## Acceptance Criteria

- [ ] 首页有"户型图"入口，可进入户型图列表
- [ ] 列表页可新增（拍照/相册）、重命名、删除户型图
- [ ] 户型图详情页点击空白 → 新建柜子后自动挂载在点击位置
- [ ] 户型图详情页可挂载已有柜子
- [ ] 柜子标记显示名称+封面缩略图，点击跳转柜子详情
- [ ] 长按可移动柜子标记位置
- [ ] 删除户型图后柜子保留（floorPlanId 置空），无数据丢失
- [ ] Room 数据库迁移正确（老版本数据升级不崩溃）
- [ ] 未挂载柜子的用户（老数据）功能不受影响

## Out of Scope

- 房间/区域标注
- 户型图 AI 识别
- 柜子在户型图上的批量管理
